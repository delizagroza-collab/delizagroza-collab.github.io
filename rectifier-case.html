00 · SCOPE

研究范围 / Scope

课程题目规定了 R、RL 两类负载和 α=30°、60°、90°、120° 四个典型触发角。完成这些必做工况后，我保留相同电源、触发与数据处理口径继续做三项扩展：用 5° 步长扫描 α，观察结论是否具有连续趋势；加入续流二极管，量化负压区与电流纹波的变化；构造 RLE 工况，用平均功率方向检验有源逆变。

01Modeling / 系统建模从课程参考拓扑到可运行的四晶闸管 Simulink 模型，并配置触发、测量和负载支路。 02Experiment Design / 工况设计8 个典型工况用于直接比较，19 个控制角点用于检查趋势连续性。 03AI-assisted Iteration / AI 协作用 AI 辅助拆解问题、修改脚本和提出检查项，再回 MATLAB/Simulink 实际运行。 04Data Pipeline / 数据处理Scope → Workspace → 稳态窗口 → 指标计算 → 批量绘图，保持不同工况使用同一口径。 05Freewheeling Diode / 续流分析比较普通 RL 与 RL+FD，分别看输出负压区、电流连续性和平均功率。 06Validation / 工程验证不以 α>90° 直接下结论，而以 Ud_avg、Iavg 与 Pavg 三个条件判断能量方向。

这个项目里 AI 用得比较多，但主要集中在工作方法上。遇到批量仿真、数据口径、代码报错或大控制角下的解释问题时，我会先把问题拆成可检查项，再回 MATLAB/Simulink 跑一遍。下面保留三类能够和实际脚本对应起来的例子。

07 · VALIDATION

RLE 工况下的有源逆变验证 / Active Inversion

普通 RL 在 α>90° 时可以出现负压区，但无源负载不能持续向交流侧供能。最终验证因此引入直流电动势 EM=220 V，并将电感改为 L=1 H 以维持较连续的电流。报告采用 Ud_avg<0、Iavg>0、Pavg<0 三个条件共同判断。

RLE · α = 120° · R = 20 Ω · L = 1 H · EM = 220 V
Ud_avg−100.11 V
Iavg+5.99 A
Pavg−563.44 W

Ud_avg 为负而 Iavg 仍为正，说明晶闸管电流方向没有反转；Pavg 为负则说明平均功率已经由直流侧流向交流侧。这里的判断依据是功率方向，而不是只看控制角大小。

关键理论公式 / Core equations
R 负载：Ud = Um(1 + cosα) / π
连续电流 RL：Ud = (2Um/π) cosα
Pavg = mean(ud · id)

α>90° 仅说明连续电流理想公式给出负平均电压；有源逆变还需要直流侧能源与负平均功率。
